# 小狐爱说话

一个本地优先的 Flutter AI 角色扮演聊天应用。

它把普通的 AI 对话扩展成一段可以长期发展的角色关系：你可以创建不同的人设、设定世界背景，让角色在连续剧情中保留记忆，并通过好感度与情感状态逐步改变回应方式。

当前版本：**1.1.2**

## 项目特色

- **沉浸式角色扮演**：角色会根据身份、性格、关系、情绪和当前场景自然回应，并持续推进剧情。
- **多角色人设卡**：支持简易模式与详细模式，详细模式可以补充说话风格、关系、目标和示例对话。
- **角色级状态**：每个角色拥有独立的好感度和情感状态，切换角色不会混用状态。
- **本地优先**：聊天记录、人设、总结和情感数据默认保存在本地 SQLite 数据库中。
- **自带 API Key**：支持 DeepSeek、OpenAI 兼容接口和自定义端点，模型服务由用户自行配置。

## 核心功能

### 角色与剧情

- 多角色创建、切换、编辑和删除
- 简易人设 / 详细人设二选一
- 用户人设、世界背景、开场白和聊天背景
- 角色包完整导入 / 导出
- 继续剧情：让角色在没有新用户台词时自然推进场景
- 沉浸式演绎规则：普通的摸头、拥抱、牵手、安慰、撒娇等虚构互动优先按剧情回应

### 好感度系统

- 每四轮对话综合判断一次好感度变化
- 先对四轮互动做简单总结，再计算净变化
- 变化范围为 `-0.3 ~ +0.8`
- 普通互动控制变化幅度，高强度事件才允许明显变化
- 好感度变化会立即保存到角色状态
- 每条历史记录保存：
  - 20 字以内的简要原因
  - 非零变化对应的 30～120 字详细原因
- 好感度为 0 时仍保存“为什么没有变化”的简要原因
- 好感度卡片展开后显示详细原因，不再重复展示原始聊天内容
- 重新生成回复不会删除已有历史日志，旧记录会继续作为历史快照保留

### 情感引擎

情感系统使用四个维度描述角色的内在状态：

- 对外亲近感
- 对外攻击性
- 自我肯定
- 自我压力

系统会结合互动内容、情绪强度和管理员设置的灵敏度，更新角色的情感状态，并通过情绪标签、关系阶段和 5×5 情绪网格展示给用户。

高压情绪允许角色表达痛苦、犹豫和失控感，但会避免美化自毁行为，并优先引导剧情走向暂停、求助、安慰、稳定和缓和。

### 上下文记忆

- 默认每八轮归档一次
- 一条用户消息及其完整 AI 回复算作一轮
- 日记式总结按照四个固定维度组织：
  - 剧情总结
  - 事件记忆
  - 对用户的关系和心情
  - 待会要做什么
- 没有实际进展的维度可以省略，不会为了凑模板编造内容
- 每段有效内容限制在 20～120 字
- 当前八轮原始对话优先于旧总结
- 手动编辑后的总结作为最高优先级参考
- 支持根据对应历史轮次重新生成旧总结
- 支持书签模式，将重要消息长期注入上下文

### 结构化 AI 回复

AI 回复使用 JSON 封装，用户只会看到 `reply` 正文，内部字段不会泄露到聊天气泡。

```json
{
  "reply": "角色给用户看的正文",
  "quick_replies": ["继续说", "换个话题"]
}
```

结构化输出还为后续扩展保留了额外字段空间。正文会保留自然分段和换行，流式输出、补写和异常格式也会经过容错处理，避免 JSON 外壳、好感度标记或快捷回复格式显示给用户。

### 聊天体验

- SSE 流式输出
- 自然段落与换行保留
- 回复长度上下限设置
- 下流 / 正常 / 优雅三档快捷回复语气
- 快捷回复自动生成两个不同方向的后续输入
- 消息编辑、复制、撤回和重新生成
- 深色 / 浅色主题
- 多平台运行

## 技术栈

- Flutter / Dart
- Material 3
- Provider
- SQLite（sqflite）
- DeepSeek API（OpenAI 兼容格式）
- SSE 流式请求
- FTS5 全文搜索

支持的平台目录包括：

`Android` · `iOS` · `Windows` · `macOS` · `Linux` · `Web`

## 项目结构

```text
lib/
├── models/       数据模型：角色、对话、消息、情感和日志
├── providers/    状态管理：聊天、角色、对话和主题
├── services/     API、数据库、上下文、记忆、好感度和情感服务
├── pages/        聊天、角色设置、总结管理、管理员面板等页面
└── widgets/      聊天气泡、输入框、情感网格等通用组件

test/
└── 单元测试与解析、记忆、状态、结构化回复相关回归测试
```

## 开始运行

需要安装 Flutter 和对应平台的开发环境。

```bash
flutter pub get
flutter run
```

首次使用时，在应用内配置 API Key、接口地址和模型。API Key 由本地应用保存，不会提交到本仓库。

## 测试

```bash
flutter test
dart analyze lib
```

## 构建

```bash
flutter build apk --release
```

也可以使用 Flutter 支持的其他平台构建命令。

这是一个个人项目，重点是探索本地优先的 AI 角色扮演、长期上下文记忆、好感度和情感状态系统。项目中的角色扮演内容属于虚构创作，实际可生成内容还会受到模型服务商和应用安全规则限制。
